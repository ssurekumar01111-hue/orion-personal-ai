# Orion

Orion is a private personal AI operating layer with local memory and workspace tools.

## Project Overview

Orion is a private personal AI operating layer that provides local memory, workspace tools, and a personal model to help users manage projects, tasks, decisions, and skills.

## Running the Backend and Frontend

To run the backend:
```bash
uvicorn app.main:app
```

To run the frontend:
```bash
npm run dev
```

Ensure all dependencies are installed before running.
